
# 🛡️ CreditGuard AI

> Proof-driven financial intelligence built on Creditcoin.

## What is CreditGuard?

CreditGuard is an AI-powered financial agent that uses verified cross-chain blockchain data to make explainable decisions and trigger policy-controlled on-chain actions.

### Core Flow

Verified Data
↓
AI Agent
↓
Policy Decision
↓
Creditcoin Action
